# Lumen bundled learning content

The ten literary works bundled in the Lumen Classic Library are public-domain
works. The mobile PDF editions were generated from the following Project
Gutenberg plain-text editions:

- Pride and Prejudice - https://www.gutenberg.org/ebooks/1342
- Jane Eyre - https://www.gutenberg.org/ebooks/1260
- Wuthering Heights - https://www.gutenberg.org/ebooks/768
- Frankenstein - https://www.gutenberg.org/ebooks/84
- Alice's Adventures in Wonderland - https://www.gutenberg.org/ebooks/11
- A Tale of Two Cities - https://www.gutenberg.org/ebooks/98
- The Picture of Dorian Gray - https://www.gutenberg.org/ebooks/174
- The Time Machine - https://www.gutenberg.org/ebooks/35
- Dracula - https://www.gutenberg.org/ebooks/345
- The Great Gatsby - https://www.gutenberg.org/ebooks/64317

Project Gutenberg license information:
https://www.gutenberg.org/policy/license.html

Lumen can also search one page of the Project Gutenberg public catalog when
the user requests it. Importing a result downloads that ebook's plain-text
edition and available cover from `www.gutenberg.org`, then creates a local PDF
for reading on the device. The generated cover page identifies the Project
Gutenberg ebook number. Project Gutenberg's terms and license continue to apply
to those downloaded editions.
